# 6G-Research-Lab
Hands-on physical-layer experiments building toward 6G — one new study at a time.

This is a working lab, not a finished product. Each topic here is a practical experiment: a simulation I built, a result I can reproduce, and a plain-English explanation of what the code actually does and why it matters. New work gets added as I complete it.

The focus is 6G physical-layer and radio topics — sensing, waveforms, MIMO, and the techniques that will shape next-generation wireless.
